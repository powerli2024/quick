# Quick 项目注册音频裁剪落地技术方案

> 版本：v1.0  
> 日期：2026-08-29  
> 范围：根据已知注册文本，从 s1/s7 的 raw、MossFormer-SE 候选中定位并裁剪注册词  
> ASR 主链见《ASR落地技术方案》，CTC 与 `q_kw` 见《CTC与q_kw落地技术方案》。

## 1. 结论

裁剪必须是可回退的新候选视图，而不是覆盖原音频：

```text
full         完整候选，永久保留
core         对齐器给出的目标词核心，仅用于审计
keyword_ctx  目标词加安全上下文，用于 KWS 注册
speaker_ctx  同一说话人的较长连续上下文，用于声纹 embedding
```

裁剪前必须先证明目标词“可能真实存在”；强制对齐器能给出时间，不代表音频中一定存在该词。裁剪后必须重新计算 CER、`q_kw`、声纹、噪声和下游指标。不合格时原因码为 `CROP_REJECT_KEEP_FULL`，安全回退 full。

## 2. 目标与非目标

### 2.1 目标

1. 去除目标词前后的无关人声、噪声、音乐和长静音。
2. 不切掉首音、尾音、爆破音和共振尾部。
3. 中文、英文、品牌词和混合拼写均可定位。
4. raw/SE、s1/s7 各自独立对齐，支持时间映射审计。
5. 支持所有输入长度，不设置 `max_crop_sec=3.0` 一类硬截断。
6. 裁剪结果固定目录保存、可复用、可逐 UID 审阅。

### 2.2 非目标

1. 不用裁剪掩盖选流错误。
2. 不用 ForcedAligner 时间戳充当 `q_kw`。
3. 不为了声纹时长重复、循环或复制目标语音。
4. 不跨 s1/s7 或不同分离流盲目复用边界。

## 3. 总体流程

```text
全候选 canonical PCM
  -> Qwen free CER / 初步 q_kw / VAD
  -> 文本规范与正 alias
  -> Qwen3-ForcedAligner 主定位
  -> MMS-FA/CTC 对齐独立复核或回退
  -> raw/SE 边界一致性检查
  -> core/keyword_tight/keyword_normal/keyword_wide/speaker_ctx 候选
  -> 对所有裁剪候选重新计算指标
  -> 选择 keyword_ctx 和 speaker_ctx
  -> 与 full 一起进入 s1/s7 最终选路
  -> 固定缓存、review_flat 和 reason JSON
```

## 4. 模型职责

### 4.1 Qwen3-ForcedAligner-0.6B

主裁剪定位模型，支持中英文，输出字符/单词级：

```text
text
start_time
end_time
```

优点是中英文统一、边界精度高、适合已知文本。限制是当前官方接口不输出目标存在概率，而且存在零时长 span 的公开问题。

因此仅在以下条件满足后调用：

```text
ASR/CTC/q_kw 至少有一项支持目标存在
且音频有效
且注册文本、语言、alias 完整
```

### 4.2 MMS-FA 或独立 CTC 对齐

用途：

1. 对 Qwen 边界做独立复核；
2. Qwen 出现零时长、非单调、越界时回退；
3. 提供逐 token 对齐分，辅助判断边界可信度。

MMS-FA 需对中文做冻结的拼音/罗马化，对英文做规范化。它同样不能脱离负样本校准直接证明目标存在。

### 4.3 VAD、能量和有声概率

不负责识别文本，只负责将模型边界吸附到自然语音起止位置，并检测切音风险。VAD 不作为目标存在硬门，避免弱音和音乐背景中的真实目标被删除。

## 5. 文本准备

### 5.1 中文

保存：

```text
原始汉字
规范汉字
人工确认多音字读法
无调拼音
可选带调拼音
```

Qwen ForcedAligner 使用规范汉字；MMS/CTC 使用与其 tokenizer 对应的拼音、罗马字或字符序列。

### 5.2 英文和品牌词

对每个注册词维护人工确认的正 alias。以 `hicolmo` 为例：

```text
Hi Colmo
HICOLMO
hi colmo
hey colmo
heycolmo
```

每个 alias 独立对齐，选择目标条件分最高且通过混淆 margin 的位置。不能根据本条 ASR 输出即时创建 alias。

## 6. 裁剪前准入

以下任一情况不得自动裁剪，直接保留 full：

```text
音频为空、损坏或含非有限值
注册文本或语言缺失
所有 ASR/CTC 证据均不支持目标
仅带 context 的 Qwen 输出目标，Qwen free 和独立证据均不支持
存在两个接近的目标位置且无法消歧
对齐时间越界、倒序或目标覆盖不完整
```

初期未完成 `q_kw` 校准时，可用保守准入：

```text
Qwen free alias CER 足够低
或 Qwen free 为近音且 target NLL/独立 CTC 明显支持
```

所有准入规则写入 `crop_policy.json` 并冻结 hash。

## 7. 长音频定位

不截断输入，不设固定 3 秒上限。

### 7.1 模型可整段处理

在模型明确支持长度和显存允许时整段推理，得到全局目标位置。

### 7.2 超出模型或显存限制

使用覆盖全时间轴的搜索窗口：

1. VAD 给出全部语音段；
2. 合并相邻语音段形成窗口；
3. 窗口重叠量至少覆盖“最长注册词预期时长 + 两侧最大上下文”；
4. 对每个窗口对齐全部正 alias；
5. 将局部时间映射回全局时间；
6. 按 `q_kw`、CTC margin、边界合法性选择位置。

VAD 只用于构造窗口。若 VAD 漏掉低能量区域，仍需以固定覆盖窗口补齐整个时间轴。

## 8. 核心边界与自然边界

对齐器返回：

```text
core_start = 第一个目标 token 的 start_time
core_end   = 最后一个目标 token 的 end_time
```

`core` 仅用于审计，不直接作为最终 KWS 音频，因为 CTC/NAR 时间戳可能落在声学峰值而不是完整音素边界。

### 8.1 自然边界吸附

在 core 外侧搜索：

1. 最近 VAD 起止点；
2. 短时能量低谷；
3. 有声概率下降点；
4. 不跨入下一段竞争人声的位置。

吸附不得使任何目标 token 落到窗口外。

### 8.2 初始上下文候选

第一轮实验生成：

| 候选 | 前扩展 | 后扩展 | 用途 |
|---|---:|---:|---|
| `keyword_tight` | 80 ms | 120 ms | 干扰严重时 |
| `keyword_normal` | 160 ms | 240 ms | 默认候选 |
| `keyword_wide` | 300 ms | 400 ms | 防止切掉弱首尾音 |

这些数值是实验网格，不是生产永久常量。最终通过全量数据和人工边界审阅冻结。

### 8.3 切点处理

裁剪在原采样率上按整数 sample 执行。可以增加 5–10 ms 淡入淡出，只修复切点爆音，不改变中间波形。

## 9. raw 与 SE

### 9.1 基本原则

每个 s1/s7 流的 raw、MossFormer-SE 独立对齐。不得假设 SE 一定与 raw 样本级同步。

记录：

```text
raw_sample_count
se_sample_count
duration_ratio
estimated_delay_ms
raw_core_start/end
se_core_start/end
boundary_delta_ms
```

### 9.2 共识规则

```text
raw和SE均高置信且指向同一位置
-> 生成加权共识边界，同时保留各自边界

只有raw可靠
-> raw独立裁剪
-> 仅在时间映射验证通过时将边界映射给SE

只有SE可靠
-> SE产生自己的裁剪候选，不覆盖raw

raw和SE指向不同出现位置
-> CROP_RAW_SE_CONFLICT，保留full并进入审阅
```

不同 s1/s7 role、不同 spk 流之间绝不传递边界。

## 10. 多次出现与竞争人声

对齐结果允许返回多个位置：

```text
occurrence_id
start/end
target_score
confusable_margin
speaker_ref_score（若有）
```

选择规则：

1. 只有一个明显最优位置：自动裁剪；
2. 最优位置在目标分和 margin 上明确领先：选择并保存其他位置；
3. 两个位置接近：`CROP_MULTIPLE_MATCHES_REVIEW`，不自动发布；
4. 有可靠目标说话人 reference 时，声纹只用于多个文本位置之间消歧；
5. 无 reference 时不能凭文本判断目标属于哪个说话人。

## 11. keyword_ctx 与 speaker_ctx

### 11.1 keyword_ctx

用于 KWS 注册，目标是：

```text
目标词完整
前后语音最少
竞争人声最少
音乐/噪声可控
CER和q_kw不退化
```

从 `keyword_tight/keyword_normal/keyword_wide` 中选择。

### 11.2 speaker_ctx

从目标词核心向两边扩展到同一连续说话人区域：

```text
遇到明显说话人变化、长静音、强重叠人声即停止
```

声纹所需最低有效时长必须通过 ERes2NetV2 的独立实验确定，不能为了凑时长：

```text
循环语音
复制目标词
拼接另一说话人
增加大段静音
```

若无法获得更长的同说话人区域，`speaker_ctx` 可以等于 `keyword_ctx`，并记录 `speaker_context_short=true`。

## 12. 裁剪后重算与选择

每个 full/keyword_tight/keyword_normal/keyword_wide/speaker_ctx 候选重新计算：

```text
Qwen free CER
中文无调拼音 CER / 英文 alias CER
CTC 对齐特征
calibrated q_kw（若已冻结）
target NLL / margin
speaker embedding / speaker_ref_score
p_music
p_overlap
snr_vad_db
dnsmos_ovrl
speech_ratio
extra_ratio
clip_rate
edge_voice_probability
```

### 12.1 keyword_ctx 硬规则

```text
CER_full = 0 -> keyword CER 必须为 0
CER_full > 0 -> keyword CER 不得高于 full，优先严格改善
目标token必须完整覆盖
首尾不得检测到明显切音
对齐时间必须合法
```

### 12.2 排序

在通过硬规则的候选中：

```text
L1 最低 CER
L2 最高 calibrated q_kw；未校准时只用同 UID CTC/NLL margin
L3 更低竞争人声、extra_ratio、音乐概率
L4 更好的声纹和质量
L5 选择更短且边界安全的候选
```

若没有裁剪候选通过，选择 full，不让 UID 因裁剪失败而缺失。

## 13. 缓存与去重

### 13.1 alignment key

```text
alignment_key = SHA256(
  pcm_sha256,
  wake_text,
  lang,
  alias_set_hash,
  text_normalizer_hash,
  aligner_model_hash,
  aligner_runtime_hash
)
```

### 13.2 crop key

```text
crop_key = SHA256(
  alignment_key,
  crop_policy_hash,
  start_sample,
  end_sample,
  fade_policy_hash
)
```

相同 PCM、文本、语言和模型只对齐一次。相同裁剪 sample 范围只物化一次；candidate alias 只建立映射。

## 17. 分阶段落地

### C0：审计模式

只输出 Qwen/MMS 边界和 JSON，不生成裁剪 WAV，不参与选路。

### C1：物化候选

`build_crop_candidates.py` 已实现 core 时间约束下的 `keyword_tight/keyword_normal/keyword_wide/speaker_ctx` 物化；重新计算指标，但不改变最终 winner。

### C2：离线 shadow 选路

允许裁剪候选参与离线排名，输出相对当前 full route 的逐 UID 差异。

### C3：冻结 crop policy

基于人工边界审阅和全量指标冻结 padding、边界吸附、冲突规则及 hash。

### C4：正式候选

裁剪进入主 route，但 full 永远保留且可回退。

## 18. 预期命令接口

```bash
python scripts/score_forced_alignment_manifest.py \
  --manifest "$WORK_DIR/candidate_refs_with_se.jsonl" \
  --output "$WORK_DIR/alignment.jsonl" \
  --qwen-aligner-dir /root/autodl-tmp/Qwen3-ForcedAligner-0.6B \
  --mms-fallback 1 \
  --device cuda:0

python scripts/build_crop_candidates.py \
  --manifest "$WORK_DIR/candidate_refs_with_se.jsonl" \
  --alignment "$WORK_DIR/alignment.jsonl" \
  --policy configs/crop_policy.json \
  --audio-cache-root /root/autodl-tmp/quick_audio_cache \
  --output "$WORK_DIR/crop_candidates.jsonl"

python scripts/score_crop_candidates.py \
  --manifest "$WORK_DIR/crop_candidates.jsonl" \
  --asr-jsonl "$WORK_DIR/asr_qwen_free_crop.jsonl" \
  --qkw-jsonl "$WORK_DIR/qkw_crop.jsonl" \
  --output "$WORK_DIR/crop_scored.jsonl"
```

以上裁剪脚本接口已实现。`score_forced_alignment_manifest.py` 只负责规范化外部对齐 sidecar；必须提供 `--alignment-jsonl` 或 `--align-command`，不会因只给模型路径而伪造时间戳。

## 19. 验收标准

### 19.1 契约

1. 每个发布裁剪都能追溯 full PCM、alignment key、crop key 和 policy hash；
2. 相同 crop key 波形一致；
3. 所有时间范围合法且 sample 精确；
4. 无覆盖原 full 文件；
5. 所有失败 UID 有 full 回退。

### 19.2 边界

按中文/英文、raw/SE、噪声/音乐/重叠、短/长音频分层人工抽审：

```text
目标词完整率
首音切断率
尾音切断率
错误出现位置率
多次出现未消歧率
Qwen/MMS边界差异
```

### 19.3 效果

相对 full route：

1. 每 UID 主 CER 不退化；
2. CER0 不下降；
3. calibrated `q_kw` 不出现未经解释的系统下降；
4. 声纹/CMD/Presence 不退化；
5. FRR/FAR 通过冻结验证；
6. 额外人声、音乐、静音时长有可解释改善。

### 19.4 生产边界

裁剪本地通过仍不代表生产批准。必须在冻结选中音频上完成 CMD、Presence、contest/预期测试集验证。

## 20. 回退策略

1. 无可靠对齐：保留 full；
2. Qwen 边界非法：尝试 MMS/CTC；仍非法则 full；
3. raw/SE 冲突：各自保留 full，进入审阅；
4. 裁剪 CER 退化：full；
5. 声纹/CMD 退化：KWS 可保留 keyword，但 speaker embed 回退 full/speaker_ctx；
6. crop policy 更新：新 policy hash、新目录，不覆盖旧证据。
